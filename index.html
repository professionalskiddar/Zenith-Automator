Zenith Automator

High-speed Discord message mirroring tool and trade alert forwarder. Copy text and graphics across multi-channel environments instantly.

✨ Premium Core Features

🚀 Multi-Channel Sync

Monitor specific private source channels and instantly distribute payloads to multiple destination hubs simultaneously.

🕒 Human-Jitter Timing

Introduces an automated 1–5 second "fuzzing" delay structure on top of default cooldown limits to naturally replicate real human behavior profiles.

🖼️ Attachment Cloning

Automatically isolates, replicates, and forwards raw text content, embedded formatting, graphics, and trade charts natively.

🌙 Custom Dark GUI

Features a custom, frameless design environment with an interactive diagnostic log terminal for deep connection status mapping.

🛠️ Advanced Developers Setup

If you prefer to run the core source layout explicitly via Python, follow these terminal installation steps:

git clone https://github.com/professionalskiddar/Zenith-Automator
cd Zenith-Automator
pip install requests Pillow pystray
python main.py
